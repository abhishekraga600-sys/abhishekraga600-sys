# Electronics, Embedded Systems, and Software

I build practical projects that bring together electronics, embedded systems, sensor data, and web applications.

## Featured projects

### ElectroCalc
A responsive engineering calculator with SI-aware inputs, formulas, and step-by-step results.

- [Live site](https://abhishekraga600-sys.github.io/electrocalc/)
- [Source code](https://github.com/abhishekraga600-sys/electrocalc)

### Solar Tracker
An Arduino single-axis tracker using dual light sensors and a servo-driven panel. The repository includes prototype photos, wiring references, setup, and calibration notes.

- [Project repository](https://github.com/abhishekraga600-sys/Solar_Tracker)

### LambdaSense
A front-end demonstration of lambda-sensor monitoring. Telemetry and health scores are simulated and heuristic; it is not connected to a vehicle or intended for diagnosis.

- [Project repository](https://github.com/abhishekraga600-sys/lambda-sensor)

### Task & Deadline Management System
A collaborative full-stack task-management prototype. See the repository’s contributor history for project attribution.

- [Project repository](https://github.com/abhishekraga600-sys/Task-amp-Deadline-Management-System)
